weathertools

R utilities for cleaning, harmonizing, and computing common weather metrics (Heat Index, Dew Point, Wet Bulb), plus helpers for wind direction averaging and lightweight unit conversion.

Start here

Most users only need one of these: download the PDF manual, view the repository, or install from GitHub.

Package manual (PDF) View repository

Install

Install the current version directly from GitHub:

remotes::install_github("jclark50/weathertools")

Quick examples

Compute common derived metrics from temperature + humidity:

hi <- calcHI(temp_c, rh_pct, outputunits = "degC")
dp <- calcTD(temp_c, rh_pct, outputunits = "degC")
wb <- calcWB(temp_c, rh_pct, inputunits = "degC", outputunits = "degC")

What’s inside

A small toolbox that focuses on the annoying parts of real-world weather data.

Comfort / humidity
Heat Index, dew point, wet-bulb
Wind helpers
Correct direction averaging
Units
C/F/K, Pa/hPa, mph/m/s
Harmonization
wx.units() for messy feeds
